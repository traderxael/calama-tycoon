# Calama Tycoon

Roblox mining tycoon set in Calama, Chile.

## Setup
- Install [Rojo 7.7.0](https://github.com/rojo-rbx/rojo) plugin in Roblox Studio
- Run `rojo serve` in project root
- Connect from Studio plugin

## Stages
Rajo -> Chancado -> Molienda -> Flotacion -> Fundicion -> Refineria SX-EW -> FCAB -> Puerto
